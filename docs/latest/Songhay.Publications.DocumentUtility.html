(JsonElement tags, JsonElement propeties)

Remarks

The JsonObject passed into this method should be or will be shaped like IDocument where Tag can be serialized JSON of the form:

{
    \"tags\": [...],
    \"properties\": { ... }
}

...where the tags property is an array of strings and the properties property is an object of conventional properties, named with a prefix of rx.

This use of Tag is a temporary workaround until a formal concept of Document properties can be defined.
